# Chatbot Avatar Setup

## Required Image

The chatbot is configured to use a **3D Ghibli-style avatar** of Sriya.

**File needed:** `chatbot-avatar.png`

### Specifications:
- **Format:** PNG with transparent background (recommended) or solid background
- **Size:** 400x400 pixels minimum (square ratio)
- **Style:** 3D Ghibli/anime aesthetic
- **File name:** Must be exactly `chatbot-avatar.png`
- **Location:** Place in the root directory of the portfolio (same folder as index.html)

### How to Create Your Ghibli Avatar:

1. **Use an AI Avatar Generator:**
   - [Artbreeder](https://www.artbreeder.com/) - Character creator
   - [Midjourney](https://www.midjourney.com/) - AI art (prompt: "3D Ghibli style portrait")
   - [Leonardo.ai](https://leonardo.ai/) - Anime/3D character generation
   - [PicSo](https://picso.ai/) - Text-to-anime avatar

2. **Or Commission an Artist:**
   - Fiverr or similar platforms for custom Ghibli-style artwork

3. **Or Use Your Photo with Filters:**
   - Apps like "ToonMe" or "Voila AI Artist" can cartoonify photos
   - Use Photoshop/GIMP with cartoon filters

### Once You Have the Image:

1. Name it exactly: `chatbot-avatar.png`
2. Place it in `/home/user/My-Portfolio/`
3. The chatbot will automatically use it for both the floating button and chat window

### Current Fallback:

Until you add `chatbot-avatar.png`, the chatbot will show a broken image icon. 
The functionality will still work, but the visual won't appear correctly.
